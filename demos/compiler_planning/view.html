What this executes

The Rust probe builds one input net and invokes Mithril’s existing rule table. Full runs change only which ready pair fires next. For resumed runs it clones an actual partially reduced net, including its worklist, then finishes each copy under another order. The saved parent is checked for mutation.

The CPU/accelerator costs and memory limits are an explicit synthetic contract. This demo executes compiler decisions; it does not execute an accelerator kernel. Arena cell counts exclude vector capacity, queue storage and process overhead. The graph trace is shared across the displayed scenarios because each execution solves all scenarios together.
